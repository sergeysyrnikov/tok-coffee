# Studio Nord ☕

Одностраничный сайт для кофейни **Studio Nord** — тёплый, «крафтовый» дизайн в кофейно-карамельной палитре с акцентом на атмосферу и меню.

## 🌐 Сайт

https://studio-nord.example/

## 📋 Что на сайте

- **Обложка** — полноэкранный хиро с фото, навигацией и призывом к действию
- **О нас** — история и ценности кофейни
- **Меню с ценами** — кофе, напитки и десерты
- **Отзывы гостей** — впечатления посетителей
- **Контакты и карта** — как нас найти
- **Подвал** — дополнительная информация и ссылки

## ✨ Особенности

- Чистый статический HTML — без зависимостей и сборки
- Адаптивная вёрстка: от мобильных до десктопа
- Плавные анимации и интерактивность (мобильное меню, ховер-эффекты)
- Доступность: семантические секции, `aria`-атрибуты, focus-состояния

## 🛠 Технологии

- **HTML5 + CSS** — всё в одном файле, ноль JavaScript-фреймворков
- **GitHub Pages** — хостинг и деплой

## 🚀 Запуск локально

Просто открой `index.html` в браузере — никакой установки не требуется.

## 📦 Деплой

Сайт деплоится автоматически: любой коммит в `main` сразу виден на GitHub Pages.
